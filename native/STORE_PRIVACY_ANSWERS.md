# Play Console — Data safety answers (fill form with these)

Privacy policy URL: `https://notiolive.com/privacy-policy`

## Data collected

| Data type | Collected? | Shared? | Purpose |
|-----------|------------|---------|---------|
| Email address | Yes | No (auth provider only) | Account |
| User IDs | Yes | No | Account |
| App interactions | Optional (Mixpanel) | Analytics vendor | Analytics |
| Audio files | Yes (while capturing voice) | Transcription AI (Groq) when Whisper enabled | App functionality |
| Other user content (maps, transcripts, journal) | Yes | AI providers (Anthropic etc.) to structure content | App functionality |
| Purchase history | Yes (via Stripe or store IAP / RevenueCat) | Payment processor | App functionality |

## Security practices

- Data is encrypted in transit (HTTPS).
- Users can request deletion: Profile → Delete my account.
- Users can request deletion / export via Support.

## App Store privacy (iOS) — same points

- Microphone: voice capture → mind maps.
- Product interaction / analytics if Mixpanel enabled.
- Purchases: StoreKit via RevenueCat when configured.
